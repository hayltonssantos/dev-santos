# Haylton Santos — Portfólio

Portfólio profissional de Haylton Santos, Fullstack Developer com experiência prática em React, JavaScript, HTML, CSS e Firebase.

## Sobre o projeto

Este projeto apresenta:

- Hero profissional com apresentação e links de contato
- Projetos, competências técnicas e experiência profissional
- Formação acadêmica atualizada
- Interface responsiva com tema dark e foco em acessibilidade
- Conteúdo disponível em português, inglês e espanhol
- Download do currículo em PDF

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- Lucide React

## Desenvolvimento local

Instale as dependências e inicie o servidor de desenvolvimento:

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

[Baixar currículo em português — PDF](https://github.com/hayltonssantos/dev-santos/releases/download/CV_PT_102026/Haylton_Santos_CV_PT_2026.pdf)

## Estrutura principal

- `app/page.tsx` — entrada da página
- `components/portfolio.tsx` — composição do portfólio
- `lib/i18n.ts` — traduções e conteúdo multilíngue
- `lib/language-context.tsx` — contexto de idioma
- `public/` — arquivos públicos e assets
